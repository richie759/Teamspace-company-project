# TeamSpace — Company Collaboration Website (Student Project)

A front-end prototype inspired by team collaboration tools. It includes:
- Overview dashboard with summary cards and recent conversations
- Staff directory with individual profiles, search, and department filter
- Demo team chat with multiple channels and interactive message sending
- Department cards
- Responsive layout for desktop and mobile

## Technologies used
- **HTML5** — page structure and content (`index.html`)
- **CSS3** — layout, colors, cards, responsiveness (`style.css`)
- **JavaScript** — navigation, staff filtering, chat interaction (`script.js`)
- **Google Fonts (DM Sans and Manrope)** — typography (internet connection needed for the fonts)

## How to run
1. Download and extract the ZIP file.
2. Open the `company_teams_project` folder.
3. Double-click `index.html`, or open the folder in Visual Studio Code and use the Live Server extension.
4. Select Staff directory or Team chat from the left sidebar and try the search/filter/chat features.

## Important project limitations
This is a **front-end demonstration**, not a production authentication or messaging system. Staff details and chat messages are sample data. Messages are held in page memory and are not sent to other users or saved to a server. Login/registration, secure accounts, a database, and real-time chat would require a backend such as Node.js or PHP with a database and appropriate security.

## Suggested GitHub upload steps
1. Create a repository on GitHub (for example `teamspace-company-chat`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` (or upload the extracted project folder contents).
3. To publish as a static demo, open the repository's **Settings → Pages**, choose the main branch and root folder, and save.
4. Include a short project description and screenshots if your lecturer requests them.
